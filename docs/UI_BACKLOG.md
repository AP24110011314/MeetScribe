# UI Backlog — MeetScribe

This file captures proposed frontend features or enhancements that require backend API additions or contract changes.

## Needs Backend
- Real-time WebSocket or Server-Sent Events (SSE) updates instead of 2.5-second polling on `/status`.
- Speaker diarization labels and speaker-colored waveform markers.
- Team workspace sharing and role-based permissions (Viewer, Editor, Admin).
- Calendar integration (Google Calendar / Outlook) to link meetings automatically to events.
